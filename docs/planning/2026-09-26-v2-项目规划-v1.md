## 1. 目标与范围

### 1.1 P1 必须做到（验收即以此为准）

1. 在 Web 对话框里问「**ads.ads_产销存月报 的产量怎么来的？**」，得到带 **3 条凭证**（血缘图 / 词表 / 口径公式）的答案，状态 `verified`、置信度、版本号齐全。
2. 任何结论都能点开溯源：血缘图可交互、口径卡展示公式与来源、报告可打开。
3. **危险动作拦得住**：`truncate`/`drop` 被拒；生产写与跨环境动作要求上级审批；只读自动通过；**每次判定都留痕**。
4. **模型编不出来的东西谁也编不了**：模型输出里出现回执之外的表名/字段/数字 → 被出口校验拦下（有测试）。
5. 有价值的业务知识可**经人确认后入库**（候选池 → 责任人审核 → 版本化）。

### 1.2 明确不做（本轮）

用户与权限管理整套、审批流转引擎与多人会签、调度平台**写操作**的真实落地（DataWorks/Airflow 适配）、知识图谱可视化、移动端、性能优化、多租户。

### 1.3 冻结资产（只调用、按接口复用）

数据智能内核（17 端点，**注意：内核并非只读** —— 含 `/generate/*` 且 `/analyze` 落盘报告）、`integrations/lineage-client`、`packages/dip-contracts`、审计库 `dip-pg`、对话前端（静态迭代版）。

### M1 垂直切片

| ID | 工作项 | 交付物 | 边界（不要做） | 验收（可执行） | 规模 |
| --- | --- | --- | --- | --- | --- |
| M1-01 | dsh 起壳与版本锁定 | `docs/collaboration/notes/dsh-setup.md`（Node/pnpm 版本、镜像源、token URL、已知坑）+ 锁版本写法 | 不接业务 skill、不做鉴权 | 新人照文档一次跑通；截图/录屏 | S |

| M1-03 | 血缘 skill（MCP 服务） | 包装内核 `/analyze` + `/upstream`，**带契约声明与回执**（来源端点/耗时/证据数） | 只做 1 个 skill；不碰写操作 | 经 MCP 被调用返回结构化结果；`gate` 绿 | M |
| M1-04 | 模型网关（薄层） | OpenAI 兼容入口；配置即可换模型；限流与记账字段 | 不做提示词工程 | 换模型只改配置（给一段 diff 证明） | M |
| M1-05 | 出口事实校验器 | 入参（模型文本 + 回执白名单）→ 越界即拦，`dip-contracts/guards.py` | 不依赖模型实现 | **3 正例 + 3 反例**：编造表名/字段/数字被拦 | M |
| M1-06 | 端到端串起来 | 一条命令起 dsh + skill + 网关，走完 M1 验收问题 | — | 输出存 `docs/evidence/m1-*.txt` | S |

**M1 特有陷阱（已在验证中实测）**：表名/字段名含中文（`ads.ads_产销存月报`），用 ASCII 正则做白名单会**漏检全部中文标识符**——必须 Unicode 感知（`\p{L}\p{N}` + `u`；Python 用 `re.UNICODE` + `[\w\u4e00-\u9fff]`），且**要有中文用例**。

## 5. 验收与演示

**一条验收路径**（每条都要有存证，存 `docs/evidence/`）：

1. 一条命令起全栈（PG + 内核 + 平台 + dsh 壳）
2. 在对话框问旗舰问题 → 得到答案 + 3 条凭证 + `status/confidence/version`
3. 点开凭证：血缘图可交互、口径卡有公式与来源（行号缺失时明确标注"文件级"）
4. 触发一次危险动作（`truncate`）→ 被拒 + 审计可查
5. 触发一次生产写 → 要求上级审批 → 审批后被放行（令牌不可复用）
6. 构造一次"模型编造表名" → 被出口校验拦下
7. 知识回写：一条无来源脚本的候选 → 入不了库

**存证要求**：命令 + 原始输出（不截断关键行）+ 截图；**反例必须留**。

## 6. 风险清单

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| **dsh 是 v0.1 预览版**，API 可能破坏性变更 | 前端与插件层返工 | 锁版本不追 latest；**契约锁在 MCP 层**，外壳可替换；只让一人碰 dsh |
| DeepSeek API 波动/限流/成本 | M1 就卡住（**已决定不保留无模型降级**） | 网关层做超时/重试/降级**提示**（不静默失败）；预算上限与调用记账 |
| 知识回写把幻觉灌进知识库 | 污染地基，后面全错 | 候选池 + 责任人审核 + 版本回滚 + **无来源不入库** |
| 中文标识符导致校验静默失效 | "以为拦住了" | 出口校验/防火墙**必须有中文用例**；未命中策略显式落默认档并留痕 |
| 内核虽冻结但**并非只读** | 安全假设错误 | 客户端保持只读；任何写类调用必须过防火墙；`/analyze` 落盘报告视为已知副作用 |
| 业余时间、节奏不稳 | 里程碑拖期 | 任务一周可交、互不依赖；每周 15 分钟同步；**宁可小步快跑，不要大 PR** |
| Windows/WSL 环境差异 | 脚本在别人机器上跑不动 | 启动脚本自动探测 venv 布局；**中文 Windows 下 HTTP 验证必须显式 UTF-8**（否则误判为产品缺陷） |
