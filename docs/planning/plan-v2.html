0. 一页纸

项结论
目标对话即入口，回答必带凭证；能力以 Skill 增长，内核不动
技术底座DeepSeek API（薄网关）＋ DeepSeek Harness（dsh） 作插件运行时与 Web 壳 ＋ MCP 作 skill 通道
安全防火墙独立服务（三档：自动通过 / 需上级审批 / 禁止）＋ 出口事实校验（回执白名单）＋ 全链路审计落库
知识双通道：结构化通道（唯一可产出结论）＋ 文档通道（WeKnora，仅背景）

当前进度垂直切片的技术前提已验证；T3/T4 仅有原型，尚未进仓库
人力假设2~4 人业余时间，任务互不依赖、一周一轮

1. 目标与范围

1.1 P1 必须做到（验收即以此为准）

  • 在 Web 对话框里问「ads.ads_产销存月报 的产量怎么来的？」，得到带 3 条凭证（血缘图 / 词表 / 口径公式）的答案，状态 verified、置信度、版本号齐全。
  • 任何结论都能点开溯源：血缘图可交互、口径卡展示公式与来源、报告可打开。
  • 危险动作拦得住：truncate/drop 被拒；生产写与跨环境动作要求上级审批；只读自动通过；每次判定都留痕。
  • 模型编不出来的东西谁也编不了：模型输出里出现回执之外的表名/字段/数字 → 被出口校验拦下（有测试）。
  • 有价值的业务知识可经人确认后入库（候选池 → 责任人审核 → 版本化）。

    • 1.2 明确不做（本轮）

    用户与权限管理整套、审批流转引擎与多人会签、调度平台写操作的真实落地（DataWorks/Airflow 适配）、知识图谱可视化、移动端、性能优化、多租户。

    1.3 冻结资产（只调用、按接口复用）

    数据智能内核（17 端点，注意：内核并非只读 —— 含 /generate/* 且 /analyze 落盘报告）、integrations/lineage-client、packages/dip-contracts、审计库 dip-pg、对话前端（静态迭代版）。

    2. 里程碑

    #里程碑完成标志（可演示）依赖
    M1垂直切片打通在 dsh 的 Web 壳里问一句业务问题 → 经 MCP 调到我们的 skill → 返回带凭证的结构化答案无

    M4前端与演示固化一条命令起全栈 → 走完验收路径 → 出截图/日志存证M1、M2
    节奏建议：M1 两周内必须出结果（它决定后面所有事是否成立）；每个里程碑结束做一次 15 分钟演示 + 复盘。

    3. 工作分解（拆到「一个 PR 能合并」）

    M1 垂直切片

    ID工作项交付物边界（不要做）验收（可执行）规模

    M1-02skill 契约声明与校验器dip_skills/spec.py（9 类字段，YAML 解析）+ 缺失/越界字段即报错 + 模板样例不做 skill 运行时缺字段的声明被拒（有测试）；模板可复制M
    M1-03血缘 skill（MCP 服务）包装内核 /analyze + /upstream，带契约声明与回执（来源端点/耗时/证据数）只做 1 个 skill；不碰写操作经 MCP 被调用返回结构化结果；gate 绿M
    M1-04模型网关（薄层）OpenAI 兼容入口；配置即可换模型；限流与记账字段不做提示词工程换模型只改配置（给一段 diff 证明）M
    M1-05出口事实校验器入参（模型文本 + 回执白名单）→ 越界即拦，dip-contracts/guards.py不依赖模型实现3 正例 + 3 反例：编造表名/字段/数字被拦M
    M1-06端到端串起来一条命令起 dsh + skill + 网关，走完 M1 验收问题—输出存 docs/evidence/m1-*.txtS

    M1 特有陷阱（已在验证中实测）：表名/字段名含中文（ads.ads_产销存月报），用 ASCII 正则做白名单会漏检全部中文标识符——必须 Unicode 感知（\p{L}\p{N} + u；Python 用 re.UNICODE + [\w\u4e00-\u9fff]），且要有中文用例。

    5. 验收与演示

    一条验收路径（每条都要有存证，存 docs/evidence/）：

  • 一条命令起全栈（PG + 内核 + 平台 + dsh 壳）
  • 在对话框问旗舰问题 → 得到答案 + 3 条凭证 + status/confidence/version
  • 点开凭证：血缘图可交互、口径卡有公式与来源（行号缺失时明确标注"文件级"）
  • 触发一次危险动作（truncate）→ 被拒 + 审计可查
  • 触发一次生产写 → 要求上级审批 → 审批后被放行（令牌不可复用）
  • 构造一次"模型编造表名" → 被出口校验拦下
  • 知识回写：一条无来源脚本的候选 → 入不了库

    • 存证要求：命令 + 原始输出（不截断关键行）+ 截图；反例必须留。

    6. 风险清单

    风险影响对策
    dsh 是 v0.1 预览版，API 可能破坏性变更前端与插件层返工锁版本不追 latest；契约锁在 MCP 层，外壳可替换；只让一人碰 dsh
    DeepSeek API 波动/限流/成本M1 就卡住（已决定不保留无模型降级）网关层做超时/重试/降级提示（不静默失败）；预算上限与调用记账
    知识回写把幻觉灌进知识库污染地基，后面全错候选池 + 责任人审核 + 版本回滚 + 无来源不入库
    中文标识符导致校验静默失效"以为拦住了"出口校验/防火墙必须有中文用例；未命中策略显式落默认档并留痕
    内核虽冻结但并非只读安全假设错误客户端保持只读；任何写类调用必须过防火墙；/analyze 落盘报告视为已知副作用
    业余时间、节奏不稳里程碑拖期任务一周可交、互不依赖；每周 15 分钟同步；宁可小步快跑，不要大 PR
    Windows/WSL 环境差异脚本在别人机器上跑不动启动脚本自动探测 venv 布局；中文 Windows 下 HTTP 验证必须显式 UTF-8（否则误判为产品缺陷）
