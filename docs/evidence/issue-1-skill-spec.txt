依赖修复实证：PyYAML 不再是"未声明依赖"
========================================
改动前：`pyproject.toml` 从未声明 yaml，PyYAML 6.0.3 仅由 uvicorn[standard] 的 extra 间接带入：

$ .venv/bin/python -c "import importlib.metadata as m; print([r for r in m.requires('uvicorn') if 'yaml' in r])"
["pyyaml>=5.1; extra == 'standard'"]

改动后：在干净环境里**只装 .[dev]（不含 api extra）**，PyYAML 由本项目自己带入：

$ python3 -m venv /tmp/depcheck/venv
$ /tmp/depcheck/venv/bin/pip install -e '.[dev]'
$ /tmp/depcheck/venv/bin/pip show pyyaml | grep -E '^(Name|Version)'
Name: PyYAML
Version: 6.0.3
$ /tmp/depcheck/venv/bin/pip show pyyaml | grep -i 'Required-by'
Required-by: data-intelligence-platform
$ /tmp/depcheck/venv/bin/pip show uvicorn
WARNING: Package(s) not found: uvicorn
$ PYTHONPATH=packages/dip-skills/src /tmp/depcheck/venv/bin/python -c "from dip_skills import load_skill_spec; print(load_skill_spec('templates/skill.yaml').qualified_name)"
demo.echo@1

即：uvicorn 不在的环境里依然可用 —— 旧写法在这个环境必然 ImportError。
