=========== 10. 本次踩到的坑（都已绕开，记在这里免得下次再踩）===========
  1) 中文进 URL query 必须 URL 编码：直接拼 '?subject=ads.ads_产销存月报.x' 会被 uvicorn 顶回
     'Invalid HTTP request received.' + HTTP 400（不是应用的错，是 HTTP 请求行本身非法）。
     本脚本统一用 curl -G --data-urlencode。
  2) JSONResponse 不认 datetime：候选行里有 timestamptz，直接塞 JSONResponse 会在渲染时
     TypeError: Object of type datetime is not JSON serializable；接口统一过 jsonable_encoder。
  3) 口径主体的格式校验只允许 字母/数字/下划线/点/中文 —— 测试标记里用了 '-' 会被判 invalid_subject
     （这正好说明校验是生效的：不是没写测试，是写错了就该被拦）。
