=========== 10. 坑（本轮新踩到的）===========
  1) 入库时**必须先降级旧版本、再插入新版本**：顺序反了会同时存在两条 active，
     被 uq_kb_metrics_one_active 当场拒绝（事务里也一样，约束是立即检查的）。
  2) 老库补列/换约束靠 create table if not exists 是补不上的（它对老库是 no-op），
     必须在建表语句后追加 alter table ... add column if not exists / drop constraint if exists。
