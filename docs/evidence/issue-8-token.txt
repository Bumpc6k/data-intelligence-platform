=== 1) 起服务（默认 5 分钟时效）===
  token_ttl_seconds=300  已签发=0  策略指纹=6bfcaadc1263

=== 2) 验收①：同一令牌第二次使用被拒 ===
  第一次 → {"ok":true,"reason":"ok"}HTTP 200 
  第二次 → {"detail":"令牌已使用过（一次性，不允许复用；上次使用 actor=么慌）"}HTTP 403 

=== 3) 验收②：令牌跨动作不可用（改一个字符即失效）===
  换一个字符（select 1 → select 2）→ {"detail":"令牌与当前动作不匹配（指纹不一致：令牌是给另一个动作签的）"}HTTP 403 
  原样再用一次（证明上一次的拒绝没有消费掉令牌）→ {"ok":true,"reason":"ok"}HTTP 200 

=== 4) 指纹规范化：人复制粘贴的差异不算改动 ===
  审批时给的 SQL（多行 + 结尾分号）：
    | insert into ads.ads_产销存月报
    |       select 1;
  执行方用单行、无分号的等价 SQL 去用 → {"ok":true,"reason":"ok"}HTTP 200 
  但把 SQL 里的一个字改掉（select 1 → select 2）→ {"detail":"令牌与当前动作不匹配（指纹不一致：令牌是给另一个动作签的）"}HTTP 403 

=== 5) 实时效：把时效改成 3 秒，重启后同一张令牌过期即作废 ===
  /health 读到 token_ttl_seconds = 3
  刚签发就用 → {"ok":true,"reason":"ok"}HTTP 200 
  等 4 秒（时效 3 秒）…
  过期后用 → {"detail":"令牌已过期（签发于 4 秒前，时效 3 秒）"}HTTP 403
