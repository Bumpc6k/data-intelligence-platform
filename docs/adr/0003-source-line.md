# ADR-0003：来源行号由内核**新增只读端点**提供；在此之前降级为文件级

- 状态：**已采纳**（2026-09-23，用户拍板 2A）
- 相关：工作项 W-113；《设计说明书》§3.3「来源行」

## 背景

设计要求"来源精确到文件 + 行号"，而实测内核只给 `source_script`（如 `examples/warehouse/ads/ads_产销存月报.sql`），没有行号。
平台与内核是两个仓库，平台无法直接读内核的文件系统。

## 决策

1. 内核**新增一个只读端点**（只新增、不改现有契约，向后兼容）：按 `file` + 特征串返回片段与行号。
   该端点由内核仓库负责实现，平台通过 `lineage_client` 调用（接口一旦可用，客户端加一个方法即可）。
2. **在端点就绪之前**，平台侧按文件级来源展示，并在凭证卡上标注「行号待补」——
   绝不假装精确（`Source.precise` 属性即该判断）。
3. 被否掉的备选：改动 `/kb/search` 现有响应结构加字段（动了既有代码与测试，风险高于新增端点）。

## 后果

- 好：内核现有行为零影响；平台侧无需临时 hack。
- 代价：短期内溯源强度是"文件级"；文案必须在界面上如实标注。
