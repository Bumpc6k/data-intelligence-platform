# ADR-0001：与数据智能内核只走 HTTP 契约

- 状态：**已采纳**（2026-09-22）
- 决策人：产品/架构（用户拍板）

## 背景

SQL 血缘解析、业务口径知识库、HTML 报告、海豚插件已在内核仓库 `sql-lineage-mvp` 完成并冻结（标签 `v1.0-kernel`，454 个测试）。
新平台（本仓库）需要这些能力，但不能把内核重写一遍，也不能让两个仓库互相 import 内部模块——否则版本地狱、无法独立部署。

## 决策

1. 新仓库**只通过 HTTP 调用**内核的 17 个端点，客户端集中在 `integrations/lineage-client`（工作项 W-113）。
2. 两个仓库**互不 import 内部模块**；内核的内部重构（分层、拆包）不影响平台。
3. 契约以内核仓库的 `contracts/openapi.yaml` 为唯一真相，跨仓库变更走"契约先行"。

## 后果

- 好：两边可独立部署、独立测试；内核冻结后，平台开发不会被内核重构打断。
- 代价：多一次网络往返；内核响应里的历史包袱（如参数名不统一、失败也返回 HTTP 200）
  必须由客户端消化，不能让业务代码感知（见 `lineage_client/client.py` 的设计要点）。
