# ADR-0004：Agent 规则优先、LLM 兜底

- 状态：**已采纳**（2026-09-23，用户拍板 3A）
- 相关：工作项 W-114（规则模式）/ W-115（LLM 模式）

## 背景

内核自带的 `/kb/ask` 是规则式问数，但实测它把整句当实体（`entity="ads.ads_产销存月报 产量怎么来"`）、
`evidence.metrics` 为 0——不能当问答引擎复用。同时平台必须保证：**没有 LLM key 也能跑通验收路径**。

## 决策

1. **规则层先答**：实体识别（表/字段/中文名/上下文回填）+ 意图判定（关键词表 + `/kb/ask` 的 `intent` 作加分信号）
   + 工具计划，全部确定性实现，不依赖模型。
2. **LLM 只做三件事**：拆复合句、实体缺失时的澄清话术、答案措辞与建议追问生成。
3. **事实一律来自内核**：数字/公式/表名/血缘不允许由 LLM 生成（防"编证据"）。
4. 两种模式的**结论、证据、status 必须完全一致**（只允许措辞不同），由测试强制。

## 后果

- 好：演示与验收不依赖外部模型；结论可复现、可审计。
- 代价：复杂问句的首次理解不如大模型；靠"建议追问"引导用户把问题问清楚。
