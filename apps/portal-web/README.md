# portal-web（B4 静态迭代版）

由定稿原型 `200-chat-final` 改造而来，**零构建**（无 Node 依赖）：原生 DOM + fetch 调 `/api/agent/ask`。

- 打开方式：由 portal-api 托管 → http://127.0.0.1:18100/app/
- 设计基线仍是《设计说明书》：结论带凭证、status 徽标、工具耗时可见、深色主题可切
- 与原型差异：消息流、凭证、工具步骤全部来自**真实接口返回**；接口不可用时明确显示离线，不回退成假数据
- B4 后续（正式版）：Vite + TS + Pinia + 自有对话组件层（W-121~W-123），第三方 Chat UI 只出现在适配层
